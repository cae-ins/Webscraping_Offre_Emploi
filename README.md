## 🕸️ Projet : Webscraping des Offres d’Emploi – ANStat CI

## 🎯 Objectif :
Développer une pipeline complète de collecte, d’analyse et de visualisation des offres d’emploi en ligne à partir de diverses plateformes (ex. Novojob, Emploi.ci, etc.), afin de produire des indicateurs sur le marché du travail.

## 📁 Arborescence du dépôt :

# Webscraping_Offre_Emploi/
# ├── automate/           # Scripts d'automatisation du scraping (parfois Selenium)
## ├── data/               # Données collectées (.csv, .xlsx)
## ├── docs/               # Documents de référence, manuels, documentation
## ├── environment/        # Fichiers pour la configuration d'environnement (conda, yml)
## ├── indicateurs/        # Scripts de calcul des indicateurs d'emploi
## ├── notebooks/          # Notebooks Jupyter pour analyse et visualisation
## ├── reports/            # Rapports produits ou en cours de rédaction
## ├── scripts/            # Scripts principaux de scraping et prétraitement
## ├── test_analyse/       # Tests, expérimentations ou traitements exploratoires
## ├── README.md           # Présentation du projet
## ├── etapes_git.txt      # Fichier de suivi pour les commandes Git utilisées
